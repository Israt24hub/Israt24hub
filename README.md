### Featured work

**[Praxis Lab](https://praxis-lab-seven.vercel.app/)** · interactive learning platform, in progress · [code](https://github.com/Israt24hub/Praxis-Lab)

A site for learning AI by seeing what happens inside a model, experimenting with it, and writing up the results honestly. An eight-path curriculum from mathematics to LLMs and research writing; lessons whose experiments compute in the browser, such as gradient descent fitting a line with live training and test error; a 15-step project workflow with a full guide to leak-free data splitting; and a research-writing guide built around never inventing results or references. The first two complete lessons are live and the rest of the curriculum is mapped. Next.js, TypeScript and Tailwind CSS, with light, dark and chalkboard themes.

**[LeakGuard](https://github.com/Israt24hub/leakguard)** · Python library

Finds data leakage in tabular datasets: columns that predict the target suspiciously well, columns the whole model depends on (drop-column test), identifiers, duplicates, train/test overlap, and scores that collapse on a past-to-future split. Command-line tool with CI-friendly exit codes, tested on Python 3.10–3.13.

**[The Column That Fooled Every Model](https://israt24hub.github.io/data-leakage-explained/)** · interactive explainer · [code](https://github.com/Israt24hub/data-leakage-explained)

A web page where you switch columns on and off and a model trained in your browser shows how one leaky column inflates its score. Logistic regression, ROC curves and the synthetic data are all written from scratch in JavaScript.

**[Chime Gate](https://israt24hub.github.io/chime-gate/)** · creative coding · [code](https://github.com/Israt24hub/chime-gate)

A curtain of verses hanging in a temple doorway that parts under your cursor and rings like wind chimes. Rope physics (Verlet integration with follow-the-leader constraints) drawn on canvas, sounds synthesised with the Web Audio API, no libraries.

### Team projects

**[AI Medical Pre-Screening Assistant](https://github.com/RRM006/cse499-project-EHR-azk-2026)** · CSE499 capstone, team of 3, in progress

Patients describe their symptoms aloud in Bangla, Banglish or a regional dialect, and the system turns that into a structured pre-screening report for the doctor. Benchmarking 12 speech-recognition models on real dialect speech found that even the best one has a 46.94% word error rate, so the design moved from a one-pass pipeline to a conversational system that asks follow-up questions to fill the gaps.

### More projects

**[Beanscape](https://israt24hub.github.io/beanscape/)** · website, in progress · [code](https://github.com/Israt24hub/beanscape)

An independent encyclopedia of coffee, in English and Bangla. The homepage opens with a bean-to-cup sequence rendered in WebGL, and *Discover Coffee* lets you search and filter 16 drinks. Plain HTML, CSS and JavaScript with no build step, checked by Playwright tests in CI before every deploy.

**[Study Hub](https://israt24hub.github.io/study-hub/)** · website · [code](https://github.com/Israt24hub/study-hub)

My NSU course notes, summaries and reports, organised by course, searchable and free to download. There is no server: documents are added through the GitHub API, and lecturers' slides stay AES-256 encrypted in the public repository until a visitor enters the password.

**[Bangla Sentiment Analysis](https://github.com/Israt24hub/bangla-sentiment)** · NLP, in progress

Fine-tunes BanglaBERT to classify noisy Bangla social-media comments as positive, negative or neutral (SentNoB dataset), compared against a majority-class guess and a TF-IDF baseline. Duplicates are removed before splitting and the test set is used once. Results will be added after the final training run.

**[Bangla Digit Recognizer](https://github.com/Israt24hub/bangla-digit-recognizer)** · computer vision, in progress

A web app where you draw a Bangla digit (০–৯) and a small CNN trained on NumtaDB reads it in the browser with ONNX Runtime Web, so nothing is uploaded. The app and the training notebook are built; the model and its results will be published after training, evaluated both on a random split and on a whole NumtaDB source held out to test new writers and scanners.
